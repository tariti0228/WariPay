# WariPay

割り勘管理アプリケーション

## 機能

- イベントの作成と管理
- 参加者の追加と管理
- 支払いの記録と計算
- ダークモード対応

## 技術スタック

- React Native
- Expo
- TypeScript
- Drizzle ORM
- SQLite

## 開発環境のセットアップ

1. リポジトリのクローン
```bash
git clone https://github.com/tariti0228/WariPay.git
cd WariPay
```

2. 依存関係のインストール
```bash
npm install
```

3. アプリケーションの起動
```bash
npx expo start
```
